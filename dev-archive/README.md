# dev-archive

The live mod source and tools for Visceral RE3.

- `tools/re-engine/relax_re3.py` - the relaxed body pose on every weapon (Jill and Carlos) and the hunch fix, the
  RE2 recipe with RE3's paths. `motlist_splice.py`, `motlist_relax.py` and `pak_pull.py` are copied unchanged from
  visceral-re2-vr. The output is made from the player's own game files and is never committed here.
