# RE3's in-world options: the UBCS file folder (2026-11-07)

The requirements and open questions are written once for both games, in the repo that owns the shared code:
`visceral-re2-vr/modding-notes/2026-11-07-in-world-options-book-design.md`. RE3's part, in short (Tefa's decisions): the
UBCS file folder (brown leather, ring binder, cord, coloured tabs, clipped photos, strap and press stud), modelled in Blender
with Tefa, kept straight; X + A held 0.5 s opens it big in front of the player in the game world, the game frozen; the four
coloured tabs on the left (up / down highlights one and changes the left side's picture and description; left stick right
jumps into the options, which scroll); categories Comfort, Graphics, Settings, REFramework settings, each photo with its icon;
Tefa hand-writes the options in blue pen and designs the sliders. The smoothing sliders are in REFramework's menu meanwhile
(b008). Next week, Fable first.
