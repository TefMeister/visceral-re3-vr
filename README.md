# Visceral VR — Resident Evil 3 (2020)

**Private, and not started.** This repo exists so mod ideas for a future Visceral VR playthrough of
Resident Evil 3 (2020) have a home now. Work on the mod itself is months away, maybe more than a year.

It will be made public, and get the usual folders (`dev-archive/`, `engine-research/`,
`modding-notes/`, `mod/`), once work has actually begun.

| Folder | What it holds |
| --- | --- |
| `ideas/fresh/` | new ideas copied here from the private ideas repo, not yet picked |
| `ideas/chosen/` | ideas Tefa has chosen to keep for this mod |

Sister project: [visceral-re2-vr](https://github.com/TefMeister/visceral-re2-vr).
